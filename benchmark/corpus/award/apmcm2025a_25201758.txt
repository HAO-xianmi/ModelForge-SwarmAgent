基于最优成本方案的农业灌溉系统的优化

摘要
农业灌溉系统的优化设计对水资源高效利用与作物增收至关重要，本文考虑了土壤湿度条件、水源与农场的地理位置、管道建设成本和储水罐容量成本以及不同农作物在不同生长阶段下的需水量等因素，围绕灌溉系统的设计展开研究。

针对问题一：对土壤湿度的预测基于当地气象站的气象数据。首先对气象数据进行清洗及缺失值、异常值处理；对变量通过 Lilliefors 检验，发现不满足正态性，因此采用 Spearman rho 检验分析变量间相关性，确定相关气象变量有 T、Po、P、U、RRR。其次构建多元线性回归模型，通过回归方程显著性检验和残差项正态性检验，但发现模型预测效果较差；进一步引入 XGBoost 模型，XGBoost 模型的 R² 从多元线性回归的 0.2229 提升至 0.6134，且 MAE 和 RMSE 更低，拟合效果显著更优。最后采用 XGBoost 模型预测出当天土壤湿度 5cm_SM 值为 0.2428。

针对问题二：将解决方案分为三步：首先通过几何覆盖理论开展喷头布局规划，通过微调角度α和行列排列确定喷头布局。其次构建管道目标规划模型，得到当主管道数量与喷头列数一致时成本最小。最后构建灌溉系统布局规划模型，采用 25 个喷头、5 行 5 列的布局，其中 5 列管道由河流供水至第 3 行，剩余 10 个喷头通过储水罐供水，水罐设计容量为 35625.66L，最小建设成本为 2498502.10 元。

针对问题三：在旱灾场景（河流供水量降至问题二最优灌溉系统总流量的 80%）下，根据喷头位置将农田划分为 5 个灌溉区域，通过调整各区域供水优先级迭代 120 种水量分配方案。计算各种分配方案下作物存活和正常生长情况，得出最大正常生长面积为 0.538429 公顷，能存活面积为 0.868977 公顷。最后建立旱灾概率与储水罐应急储备比例的数学公式。

针对问题四：在问题二的基础上对灌溉系统进行优化布局。测试问题二系统是否满足要求；对每个月分别求出日总流量最大需求，以此为基准构建改进的灌溉系统布局规划模型；以成本最低为目标确定蓄水罐行数与河水引流行数；得到三个月的灌溉安排表，其灌溉量和水源比例可视化。

关键词：XGBoost 模型；几何覆盖理论；管道目标规划模型；灌溉系统布局规划模型

三、问题一：模型建立与求解
3.1 问题分析 数据预处理、相关性分析（Lilliefors 检验、Spearman rho 检验）、多元线性回归、XGBoost、模型对比。图 3-1 问题一流程图。
3.2 数据预处理 Step1 数据清洗：保留 T、Po、P、Pa、U、DD、Ff、ff3、Tn、Tx、H、VV、Td、RRR、tR 共 15 个变量。Step2 缺失值处理：直接删除法和线性插补法。图 3-2 数据集中各列缺失值情况。Step3 异常值处理：Z-Score 方法识别异常值，窗口为 3 的移动平均插值法修正；风向 DD 独热编码。
3.3 数据相关性分析 Lilliefors 检验显示正态性未通过，采用 Spearman rho 相关系数。图 3-3 Spearman rho 相关系数矩阵。土壤湿度 5cm_SM 与 T、P、Tn、Tx、Td 中度相关。选 T、Po、P、U、RRR 为自变量。
3.4 多元线性回归模型 YSM = β0 + β1 xT + β2 xPo + β3 xP + β4 xU + β5 xRRR。表 3-1 回归方程显著性检验：F 值 324.3599，显著性 2.0362e-62。图 3-4 残差直方图和 Q-Q 图。图 3-5 多元线性回归模型拟合图。表 3-2 多元线性回归模型性能指标：训练集 MAE 0.0306 RMSE 0.0395 R2 0.5840；测试集 MAE 0.0351 RMSE 0.0439 R2 0.2229。测试集 R2 仅 0.2229，预测误差较大。
3.5 基于梯度提升决策树（XGBoost）预测模型 ŷi = Σ fk(xi)。目标函数 Obj(θ) = Σ l(yi, ŷi) + Σ Ω(fk)，Ω(fk) = γ Tk + (1/2) λ ||wk||^2。最大-最小归一化 x' = (x − min(x))/(max(x) − min(x))。评价指标 RMSE、MAE、R2。参数：决策树数目 K 为 100，最小叶子数 20，学习率 0.4，正则化 γ=0.3 λ=0.3，特征采样 0.9。
表 3-3 多元线性回归模型和 XGBoost 预测模型的性能指标对比：多元线性回归测试集 MAE 0.0351 RMSE 0.0439 R2 0.2229；XGBoost 测试集 MAE 0.0146 RMSE 0.0191 R2 0.6134。XGBoost 优于多元线性回归基线模型。图 3-6 测试集拟合图。图 3-7 拟合图对比。表 3-4 土壤数据预测表，预测的当天湿度 5cm_SM 0.2428。

四、问题二：模型建立与求解
4.1 问题分析 几何覆盖理论喷头布局、供水方式判断、成本最小化。图 4-1 问题二流程图。
4.2 喷头全覆盖模型 几何覆盖原理：喷头按矩形网格排列，列数 a 行数 b。图 4-2 喷灌覆盖区域简化示意图。覆盖重叠、角度α影响、优化目标投影间距 ≤ 2r。
4.2.2 喷头行列个数计算 a = ⌈L/(2 r sinα)⌉ = ⌈100/(2×15 sinα)⌉；b = ⌈L/(2 r cosα)⌉。
4.3 需水量计算 最小土壤湿度 θmin = 0.124，最低土壤湿度 θreq = 0.22。Δθ = 0.096。每平方米 5cm 厚度土壤质量 m土 = md S h = 1500×1×0.05 = 75 kg。当天作物单位面积最大需水量 m水 = m土 Δθ = 7.2 kg。单个喷头覆盖面积 S = π r^2 = π×15^2 ≈ 706.86 m^2。单个喷头需水量 Q单喷头 ≈ 5089.39 L。
4.3.1 管道目标规划模型 管长成本 CL = 50 L^1.2 = 50 [(a−1) 30 sinα + 15 n cosα]^1.2。流量成本 CQ = CQ1 + CQ2，基于基尔霍夫电流定律和流体力学原理。管道总成本 min C1 = CL + CQ，约束 4 ≤ a ≤ 6，n ≤ a，33.8° ≤ α ≤ 56.2°。图 4-4 单层主管道数量和管道总成本折线图。
4.4 灌溉系统布局规划模型 储水罐容量设置满足 7 天需水量。总成本目标函数 min z(α,m) = a Σ [(1−βi) C1 + βi C2]，βi = 0 if i ≤ m else 1。储罐总成本 C2 = 5H。图 4-5 所有方案成本图。当喷头采用 5 行 5 列布局，河流供水至第 3 排，α 角度 48.10° 时系统总成本最低 2498502.10 元。图 4-6 灌溉系统布线规划示意图。

五、问题三：模型建立与求解
5.1 问题分析 旱灾下作物生长情况及储水罐应急储备与旱灾概率的关系。图 5-1 问题三流程图。
5.2 确定作物需水量 河流当天可供水量 Q80% = π r^2 V水 m 80%。作物存活水量 Q存活(t) = [θreq − θSM(t)] m土 / m水 = 75 [0.22 − θSM(t)]。单个储水罐当天可供水量 Q储 = π r^2 V水 7。
5.3 划分灌溉区域 根据喷头覆盖区域划分五个区域 S = {1,2,3,4,5}，调整优先级得 120 种供水分配方案。
5.4 计算单位面积灌溉量 Σ QPi(t) = Q80% + Q储。判别系数 λi。单位面积灌溉量 Q单(t) = Σ λi QPi(t)。目标函数 max S单位正常 = Σ S单。图 5-3 迭代 120 种情况得到的最大正常生长面积，最大正常生长面积 0.538429 公顷，能存活面积 0.868977 公顷。图 5-4 正常生长和可存活区域示意图。

七、模型评价
7.1 模型优点 1. XGBoost 模型具备捕捉复杂非线性关系及高阶交互能力，对数据分布假设较少，鲁棒性更强。2. 管道流量分析融合基尔霍夫电流定律与流体力学原理。3. 单目标规划模型可靠性高、可操作性强。
7.2 模型缺点 1. 模型未全面纳入土壤、气象等复杂变量，忽略风力影响，假设土壤均匀分布。2. 单目标规划最优解高度依赖目标函数定义。
